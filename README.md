# PCC-EBID × Global Workspace

This repository explores whether PCC-EBID-style dynamical regimes can be
identified in synthetic Global Workspace models under controlled perturbation.

The project does not assume that Pressure, Control, and Chaos correspond
directly to Global Workspace Theory constructs.

Instead, it tests whether competition, ignition, broadcast, and coordination
produce reproducible dynamical signatures that can later be evaluated using
PCC-EBID.

## Core question

Does global broadcast causally improve coordination and stability across
competing specialist processes?

## Experiment 001

A minimal Global Workspace model will contain:

- multiple specialist modules;
- competing candidate signals;
- a limited-capacity global workspace;
- an ignition threshold;
- optional global broadcast;
- downstream action selection.

Initial interventions:

- baseline;
- high ignition threshold;
- high competition/noise;
- broadcast disabled.

Primary observables:

- ignition rate;
- ignition latency;
- winner stability;
- module agreement after broadcast;
- action entropy;
- switching rate;
- reward.

PCC labels will not be assumed in advance.

The first objective is to establish robust workspace dynamics and determine
whether global broadcast causally changes coordination.
