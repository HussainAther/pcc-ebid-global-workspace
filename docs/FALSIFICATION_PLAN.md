# Falsification Plan

## Core claim under test

Global workspace broadcast should produce reproducible causal changes in
coordination, stability, and task performance.

## The project would be weakened if

1. Broadcast has no measurable effect on downstream agreement.
2. Broadcast-enabled and broadcast-disabled systems perform equivalently.
3. Ignition threshold manipulations do not affect ignition or coordination.
4. Competition manipulations fail to alter winner stability.
5. Apparent improvements are explained entirely by a trivial reward bias.
6. Effects disappear on fresh seeds.
7. Candidate PCC mappings depend mainly on arbitrary thresholds.
8. A second task fails to reproduce the relevant dynamical pattern.

## Non-claims

This repository does not claim that:

- the model is conscious;
- global broadcast is sufficient for consciousness;
- PCC-EBID detects consciousness;
- PCC variables are equivalent to Global Workspace Theory constructs;
- synthetic workspace dynamics generalize directly to humans.
